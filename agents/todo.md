1. [ ] 逻辑分块器 (Smart Segmenter)
目标：不再把整个 .md 文件当成一块布，而是按标题（Header）或段落将其切碎。

实现：编写一个 markdown_shredder.py，能把 YOLO.md 拆成 ## 简介, ## 损失函数, ## 实验结果 等独立的 Context Blocks。

2. [ ] 语义匹配引擎 (Semantic Matcher)
目标：不需要复杂的向量数据库（初期），直接用 BM25 算法 或 关键词重合度。

逻辑：

新资料提到了“GIoU Loss”。

匹配引擎在旧文件里搜“GIoU”或“Loss”。

只取出相关的 2-3 个旧段落。

3. [ ] 档案管理员 (Fetch Context) 逻辑重构
变更：_fetch_local_context 函数不再执行 read_text()，而是调用“语义匹配引擎”。

输出格式：告诉主编：“这是旧文件的片段 1（位于 ## 损失函数），这是片段 2...”

4. [ ] 主编 Prompt 协议升级 (Editor Protocol v2)
目标：让主编习惯“碎片化比对”。

指令更新：告诉主编：“你看到的是旧文件的局部，如果发现新资料与局部内容有增量，请给出局部修改指令；如果新资料完全是新领域，请指令在合适位置插入新标题。”
